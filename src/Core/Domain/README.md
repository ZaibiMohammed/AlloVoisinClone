# Domain Layer

This layer contains all entities, enums, exceptions, interfaces, types and logic specific to the domain layer.

## Folders

- **Entities**: Business objects that represent domain concepts
- **ValueObjects**: Objects with no conceptual identity used to describe domain concepts
- **Events**: Domain events that occur when something happens in the domain
- **Exceptions**: Custom domain exceptions
- **Enums**: Enumerations used in the domain
- **Interfaces**: Interfaces for domain services
- **Services**: Domain services that contain business logic
